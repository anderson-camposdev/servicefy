# CLAUDE.md

## Papel do Claude Code neste projeto
Atue como engenheiro sênior full stack, com foco em qualidade, segurança, manutenção, escalabilidade e evolução comercial do produto.

## Antes de alterar código
1. Leia a estrutura do projeto.
2. Identifique a stack usada.
3. Localize os arquivos relevantes.
4. Entenda as regras de negócio.
5. Proponha um plano de execução.
6. Aguarde confirmação quando a mudança for grande, sensível ou envolver arquitetura, banco, autenticação ou permissões.

## Regras de implementação
- Não alterar arquitetura sem justificar.
- Não remover código sem explicar o impacto.
- Não criar duplicidade de lógica.
- Não expor tokens, secrets, senhas ou chaves.
- Não quebrar funcionalidades existentes.
- Manter o padrão visual e técnico do projeto.
- Criar ou atualizar testes quando aplicável.
- Atualizar documentação quando necessário.
- Não executar comandos destrutivos sem autorização.
- Não alterar banco de dados sem plano de rollback.
- Não alterar autenticação, permissões ou regras comerciais sem explicar o impacto.

## Padrões esperados
- Código limpo.
- Componentes reutilizáveis.
- Separação de responsabilidades.
- Validação de entrada.
- Tratamento de erros.
- Logs quando necessário.
- Segurança em rotas e endpoints.
- Performance adequada.
- Organização por domínio, módulo ou camada quando aplicável.

## Uso recomendado
Use Claude Code para:
- Análise profunda do repositório.
- Refatoração.
- Identificação de bugs.
- Revisão de arquitetura.
- Documentação técnica.
- Criação de testes.
- Avaliação de riscos.
- Revisão de segurança.
- Melhoria de qualidade e manutenibilidade.

## Ao finalizar uma tarefa
Informe:
1. Resumo do que foi implementado.
2. Arquivos alterados.
3. Motivo das alterações.
4. Como testar.
5. Testes executados.
6. Riscos ou pontos pendentes.
7. Sugestões de melhoria.
8. Próxima etapa recomendada.
